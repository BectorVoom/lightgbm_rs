<objective>
Lay the shared autotune foundation that the two launch-knob wirings (13-02 build-P,
13-03 scan-W) both depend on: promote `serde` to a real rocm-gated dependency, create a
`kernels::autotune` module holding the shared `AutotuneKey` type + `log2(rows)` size-band
bucketer + `LGBM_AUTOTUNE=0` off-switch + device cache-namespace id, and add the default-on
rocm discriminator seam as a default-false `Backend` trait method.

Purpose: One place for the cross-cutting autotune plumbing so 13-02 and 13-03 only touch
their own kernel files (histogram.rs / split.rs) and can run in parallel. Honors the
spike-037/038/039 corrections (serde mandatory under `std_io`; key on the occupancy regime,
not exact rows) and the project's "backend-specific paths gate on a default-false trait
method" idiom (027/029/035).
Output: `crates/lgbm-compute/src/kernels/autotune.rs`, Cargo.toml serde promotion,
`Backend::prefers_autotune_launch_config` + RocmBackend override.
</objective>
