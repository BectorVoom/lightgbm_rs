<objective>
Close the hard parity gate and prove the e2e sign. (1) Extend the oracle `kernel_parity`
suite to pin EVERY build PSET P (via the 13-02 `LGBM_AUTOTUNE_FORCE_P` seam) and EVERY scan
WSET W (via the existing `LGBM_SCAN_CUBEDIM` seam) to the CPU f64 anchor — because autotune
may pick any variant at runtime, the whole variant set must be anchor-correct, not just the
current default (def-f8u-01: never GPU-vs-GPU). (2) Add an e2e A/B to `bench_gpu_vs_cpu`
(autotune-on vs `LGBM_AUTOTUNE=0`) confirming autotune ≥ the heuristic at the production
width and recovers the spike-040 P=1 under-partition, sign-only, ≥2 restarts. (3) Confirm the
CPU merge gate stays green and record the honest bound + first-tune cost in the SUMMARY.

Purpose: the parity contract is the merge gate; the e2e A/B is the success criterion the
blueprint demands (ship on end-to-end, not the microbench).
Output: two new parity tests, an A/B bench arm, a SUMMARY with the honest-bound caveat.
</objective>
