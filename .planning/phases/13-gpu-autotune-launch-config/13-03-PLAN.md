<objective>
Make CubeCL autotune the default selector for the split-scan `CubeDim` width `W`, wired at
the fused split launcher (split.rs:1466, the `scan_cube_dim()` consumer). Replace the
`scan_cube_dim()` default with a tuner-driven launch over a `WSET` (e.g. {32,64,128,256}),
keyed on `(num_features, num_bins)`. The scan kernel OVERWRITES fresh output slots, so the
built-in `CloneInputGenerator` is safe here (spike-038 OVERWRITE class — no fresh-output
generator). Keep `scan_cube_dim()` / `LGBM_SCAN_CUBEDIM` as the documented `LGBM_AUTOTUNE=0`
fallback + the all-W parity seam (already a fresh-read env override).

Purpose: Self-calibrate the spike-021 feature-per-lane scan width per occupancy regime
instead of the hand-tuned W=64 default; portable to any future GPU.
Output: `SCAN_TUNER` + the WSET builder + the wired launch, all in split.rs.
</objective>
