<objective>
Wave 1: build the pre-allocated-once histogram arena + the explicit `hist_t**` handle-rotation
contract (D-02) that the build->fix->subtract entry (16-04) drives. This is host-side
bookkeeping, NOT a kernel: the arena allocates a fixed slot pool ONCE (D-09), and rotation
reassigns slot indices so the larger child inherits the parent's buffer in-place and the smaller
child gets a fresh slot — with no bulk copy.

Purpose: the subtraction trick (ODL-10) requires `larger = parent - smaller` derived in the
parent's buffer; that demands a stable, anchor-testable handle contract. Phase 16 demonstrates
the rotation in ISOLATION; the cross-tree `SplitTreeStructureKernel` pool SWAP stays Phase 18.

Output: `histogram_arena.rs` (new module) + its `mod.rs` registration; anchor-tested index
bookkeeping. No tree-growth driver, no whole-tree pool manager.
</objective>
