<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Python → PyO3 (`Dataset`/`train`/`predict`) | untrusted numpy buffers (shape/dtype/contiguity) + params dict cross the FFI boundary |
| Rust panic → CPython | a panic unwinding into CPython is abort/UB |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-01 | Tampering (silent corruption) | `marshal.rs` numpy dense read | mitigate | Explicit `is_standard_layout` check + copy on non-C-contiguous arrays before reading (Pattern 3 / SC#2) |
| T-08-02-02 | Tampering/DoS | Dataset shape/label-length | mitigate | Validate `label.len()==num_rows`, rectangular shape at the boundary → `PyValueError` BEFORE indexing (Security V5; reuse ingest checks) |
| T-08-02-03 | DoS (abort/UB) | every #[pymethods]/#[pyfn] | mitigate | All return `PyResult`; `From<LgbmError> for PyErr`; no `unwrap`/`expect`/`panic!` in the crate (CLAUDE.md no-panic-across-FFI; Pitfall 6) |
| T-08-02-SC | Tampering | cargo installs (pyo3 0.27 / numpy 0.27.1 / pyo3-polars 0.26.0 / maturin) | mitigate | Crates verified in RESEARCH § Package Legitimacy Audit (crates.io API: existence, newest version, publish date, source repo) — all Approved; pinned to the exact triangle; slopcheck PyPI false-positives documented (ecosystem mismatch, not real signal) |
</threat_model>
