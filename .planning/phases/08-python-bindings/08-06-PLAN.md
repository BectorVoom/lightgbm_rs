<objective>
Deliver the Python custom-objective / custom-metric callback path and expose
`Booster.refit()` (PYB-04). Each boost iteration hands raw scores to a Python
callable and gets grad/hess back across the GIL (nested `Python::attach` while the
outer train runs under `detach`); the Python feval is marshalled into the 08-01
facade custom-metric hook (`train_custom_with_metric` / `EvalMetric::Custom`) so it
feeds the SAME eval-history loop; refit delegates to the facade method from 08-01.

Purpose: Custom callbacks + refit are the last training-behavior surface a user
needs for parity with the official package (PYB-04, SC#4). This slice makes
user-defined objectives/metrics and continued-training work end to end. The Rust
facade custom-metric hook this plan consumes is built upstream in 08-01 (the
`train_custom` → `train_custom_with_metric` extension feeding the eval-history loop);
this plan is the Python-side marshalling onto that existing hook, NOT a new Rust hook.
Output: `callbacks.rs` GIL marshalling + a `train` custom-objective/metric path +
`Booster.refit` exposed, with an A/B parity test.
</objective>
