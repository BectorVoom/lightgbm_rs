<objective>
Transcribe the two genuinely-unbuilt pieces of this phase — the ONLY new algorithms — into a
new `lgbm-compute` module, byte-for-byte from the golden-proven host code. They cannot be
imported (crate cycle: `grow_tree_on_device_driver` in `lgbm-compute` is below
`lgbm-treelearner`, memory `on-device-driver-crate-cycle-constraint`), so they are re-typed.
The risk is transcription FIDELITY (kEpsilon site, l2 asymmetry, sort tie order), not design.

1. **§6.3 bitset construction** — transcribe `construct_bitset`
   (feature_histogram_categorical.rs:424) verbatim (`n_blocks = max_val/32 + 1`; set bit
   `1<<(val%32)`) as a single-owner sequential OR into a pre-zeroed slab. NO `Atomic<i64>`
   (broken on this cubecl); for the tiny fixtures the sequential OR is bit-identical to the
   host. Plus `SetRealThreshold`: map winning inner bins → real category values via
   `bin_to_category` (host learner.rs:3648-3659), producing BOTH the real category-value bitset
   AND the inner-bin bitset (Pattern 3 two-bitset producer).
2. **§8.1 categorical evaluator** — transcribe `find_best_threshold_categorical`
   (feature_histogram_categorical.rs:93) for BOTH paths (D-02): one-hot (each category a
   singleton left set, uses the ORIGINAL `lambda_l2`) and many-vs-many (sort bins by
   `grad/(hess+cat_smooth)`, bidirectional prefix-sweep up to
   `max_num_cat = min(max_cat_threshold, (used_bin+1)/2)`, uses `lambda_l2 + cat_l2`). Reuse
   `primitives::bitonic_argsort_on` (index-only) for the ctr sort — NOT `sort_by`.

Single-owner `CubeDim::new_1d(1)` f64 anchor discipline (cubecl-cpu has no planes; def-f8u-01 —
never a second GPU f32 path). This module produces the split decision + the winner bitsets; it
does NOT wire into the driver (that is 22-04) and does NOT write `DeviceSplitInfo` slabs.

Purpose: SC #1 (bitset construction) + SC #2 (categorical eval one-hot + many-vs-many). D-02.
Output: `categorical_split.rs` with the transcribed evaluator + bitset builders and unit tests
pinning both to the host anchor values for the two committed fixtures.
</objective>
