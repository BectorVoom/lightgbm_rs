<objective>
Wire the categorical path end-to-end through the on-device grow driver — the ~70%-wiring core
of this phase. The §9 partition membership and §10 `SplitCategorical` mutation and the predict
branch ALREADY EXIST, compile, and are anchor-tested (RESEARCH Summary); this plan connects them
to the §8.1 evaluator (22-03) and the driver, replacing the two bail-out seams:

1. **`best_split.rs` dispatch seam** (:640-643, :958-960, :1814-1816) currently returns the
   `is_valid=false` sentinel on `task.is_categorical`. Replace with a call into the 22-03
   evaluator, mapping `CategoricalSplit` → `SplitScalars` (mirror the numeric mapping already in
   the function). The task flags `is_categorical`/`is_one_hot` are already set (:98-102, :239-243).
2. **`grow_driver.rs` scan_leaf** (:384) currently `continue`s on `BinType::Categorical`. Split
   the condition: keep `na_as_missing` deferred, but ROUTE `BinType::Categorical` into the
   evaluator. **Pitfall 2:** the driver must bump `sum_h` by `+2*kEpsilon` BEFORE calling the
   categorical evaluator (numeric bumps internally; categorical expects pre-bumped, host does it
   at learner.rs:2760). In the driver body, for a categorical best split: construct the real +
   inner bitsets (22-03 `set_real_threshold`), set `num_cat_threshold` on the `SplitScalars`
   (numeric uses 0, :637), then call the EXISTING `tree.split_categorical_on_device(...)`
   (tree.rs:765, §10) and `partition_categorical_on_device(...)` (data_partition.rs:686, §9)
   instead of the numeric `split_on_device` / `partition_leaf_stable`.
3. **Open Q1 isolation** — before the full structure gate (22-05), a lgbm-compute unit test
   asserts the on-device categorical partition counts equal the host `partition_categorical_stable`
   (data_partition.rs:525) for both fixtures, isolating the real-value-vs-inner-bin routing
   convention (Pattern 3 / Pitfall 4) as a standalone signal.

Everything additive, behind `LGBM_CUDA_ON_DEVICE`; numeric spine byte-unchanged (SC #4).
Purpose: SC #2 (categorical eval + partition membership routed by `CUDAFindInBitset`) + SC #3
(SplitCategorical mutation via the existing §10 entrypoint). Output: a driver that grows a
categorical tree on-device by calling the existing kernels.
</objective>
