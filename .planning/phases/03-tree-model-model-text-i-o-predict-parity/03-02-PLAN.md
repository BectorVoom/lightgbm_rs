<objective>
First feature vertical slice: load a C++-trained **regression** model `.txt`, predict raw scores identically on dense + CSR/CSC inputs, and write it back byte-identically — proving the full load→predict→write→reload spine end-to-end on the simplest objective before binary/multiclass/categorical/sub-range are layered on.

Purpose: This is the thinnest end-to-end slice that exercises the whole Phase-3 architecture (parse → faithful Tree arrays → ensemble raw-predict → byte-exact write). Choosing regression first isolates the predict-math + serialization surface with NO `ConvertOutput` transform (identity) and `num_tree_per_iteration=1` (no per-class stride), so any failure localizes cleanly. Delivers DAT-08 (read), DAT-09 (write byte-exact), and PRD-01 (raw score) — D-06 layers 1 + 2.

Output: `tree.rs` (faithful array `Tree` + predict + ToString/parse), `ensemble.rs` (`GbdtModel` + raw-predict loop), `model_text.rs` (load/save envelope), `predict.rs` (dense/CSR/CSC raw-value driver), and the layer-1 + layer-2 regression parity tests.
</objective>
