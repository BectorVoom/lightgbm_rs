<objective>
Second vertical slice: transformed prediction (`ConvertOutput`) and leaf-index prediction across binary, multiclass, and categorical-split models — proving the per-class / per-iteration indexing stride and the categorical-bitset decision path on top of the regression spine from 03-02.

Purpose: After 03-02 proves raw-score + byte-exact write on regression (the trivial `num_tree_per_iteration=1`, identity-transform case), this slice adds the harder paths: the four core `ConvertOutput` transforms (PRD-02), multiclass's `num_tree_per_iteration=num_class` stride that drives BOTH per-class output indexing AND `trees[i*ntpi+k]`, leaf-index prediction with its multiclass per-(row×iter×class) layout (PRD-03), and the categorical-split `cat_threshold` bitset traversal (the categorical Tree decode built in 03-02 is now parity-asserted). Each new fixture's byte-exact round-trip also re-confirms DAT-08/DAT-09 on binary/multiclass/categorical models.

Output: `objective.rs` (the core ConvertOutput shim), transformed + leaf-index methods on the predict driver, and the D-06 layer-3 (transform) + layer-4 (leaf) parity tests over the binary/multiclass/categorical corpora.
</objective>
