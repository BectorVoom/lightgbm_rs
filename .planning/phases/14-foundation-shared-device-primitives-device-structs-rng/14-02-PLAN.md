<objective>
Build the D-03 golden-fixture capture path: a self-contained C++/HIP harness (`hipcc` against the in-repo AMD fork as the signature reference) that launches each numeric device primitive and dumps committed, byte-idempotent golden fixtures, plus the xtask subcommand that drives it. These goldens are the anchor 14-06 replays the Rust device primitives against (numeric ops bit-exact on the cpu f64 anchor / ~1e-6 for ROCm f32; index-only argsort permutation bit-exact).

Purpose: ODL-01 requires each primitive be "anchor-pinned where it carries numeric output." Prefix-sum / reductions / argsort / percentile have no existing Rust reference (unlike RNG, which pins to the host `Random`), so they need captured C++ goldens. This is the blocking Wave-0 fixture gap from 14-VALIDATION.

Output: `xtask/cpp/primitive_capture.cu`, a CMake target, a `primitive-capture` xtask subcommand wired into `regen()`, and committed `crates/oracle-harness/fixtures/primitives/*` goldens.
</objective>
