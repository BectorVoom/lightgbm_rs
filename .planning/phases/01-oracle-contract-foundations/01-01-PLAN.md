<objective>
Build the parity-proving spine of LightGBM-rs: a Cargo virtual workspace (`lgbm-core`, `lgbm-compute` skeleton, `oracle-harness`, `xtask`), a bit-for-bit port of the C++ `Random` LCG, the f32 numerical type/constant contract, `thiserror`/`anyhow` error layering, and an oracle comparator that proves one real ~1e-6 / bit-exact comparison of Rust RNG output against a pinned, committed C++ golden.

Purpose: Every later phase is validated through this spine. The RNG is the single most parity-critical foundation (config seed derivation, bagging, feature sampling, GOSS, DART all inherit it), and the oracle harness is the validation seam every downstream parity test plugs into. This is the Walking Skeleton — the thinnest end-to-end stack that proves numerical fidelity is provable.

Output: `crates/lgbm-core` (types, errors, RNG), `crates/lgbm-compute` (Backend trait skeleton), `crates/oracle-harness` (comparator + RNG golden + reference manifest), `xtask` (dev-only C++ capture/regen), a virtual root `Cargo.toml`, committed `Cargo.lock` and `rust-toolchain.toml`, with `src/main.rs` removed.
</objective>
