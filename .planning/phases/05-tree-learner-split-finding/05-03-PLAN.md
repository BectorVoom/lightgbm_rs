<objective>
Build the minimal faithful tree-learner SPINE (D-04 spine-first): the leaf-wise (best-first) growth loop orchestrating the Phase-4 `Backend` kernels into a tree structurally + numerically bit-faithful to C++ `SerialTreeLearner::Train`, under the pinned `force_row_wise` + `feature_fraction=1.0` (no subsampling) + numeric-splits config. Covers TRL-01 (Construct→FindBest→Split flow), TRL-02 (subtraction trick + smaller-child selection), TRL-03 (leaf-wise growth with `num_leaves`/`max_depth` caps), TRL-04 (cross-feature argmax + `SplitInfo::operator>` tie-break, gain formula via the kernel), TRL-05 (numeric threshold splits + missing/zero/default-bin routing using the Plan-01 `skip_default_bin`/`na_as_missing` flags), and TRL-07 (data partition row→leaf feeding subtraction).

Purpose: This is the keystone, highest-FP-risk subsystem. It is validated at MAXIMUM diagnostic resolution: per-split snapshots = full per-bin gain arrays for every candidate feature at every split (D-06), and the full grown tree (every node + every leaf output) compared via the Phase-3 `%.17g` model-text machinery (D-07). The two-transcription cross-check (D-02a) guards the Phase-4 kernel emitter against the Phase-5 learner emitter on shared inputs.

Output: the `learner.rs` orchestrator + `leaf_splits.rs`/`data_partition.rs`/`histogram_pool.rs`/`fix_histogram.rs` modules; the `learner_capture.cpp` full-learner transcription emitting the synthetic-g/h `spine.txt` golden (per-split + per-tree); the `learner_parity.rs` assertions; and the D-02a cross-check test. Synthetic g/h are pinned to `missing_type == None` to defer the NA_AS_MISSING forward branch (RESEARCH A5) — an explicit decision recorded in the manifest.

This plan grows ONE tree from FIXED g/h — there is no boosting loop (Phase 6) and no objective producing g/h at runtime.
</objective>
