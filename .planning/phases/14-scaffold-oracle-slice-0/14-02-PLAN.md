<objective>
Wire the decide-once on-device routing fork into `SerialTreeLearner` (ODL-01), mirroring
the `resident_eligible` AND-gate idiom but reading the env ONCE at `new` (D-05 intentional
divergence). With `LGBM_CUDA_ON_DEVICE` unset the fork is never entered and the production
path is byte-identical to master.

Purpose: Add the env gate + cached eligibility + the early-return fork that consumes the
Plan 01 seam, plus the `DataPartition::from_payload` reconstruction the fork needs to
synthesize the train_inner 4-tuple. Production uses `Ok(None) ⇒ fall through` ONLY — the
host-fallback `unwrap_or_else` lives in Plan 03's oracle test, never here (D-02).
Output: `cuda_on_device_env()`, `on_device_eligible` field, `new()` init, the fork,
`DataPartition::from_payload`.
</objective>
