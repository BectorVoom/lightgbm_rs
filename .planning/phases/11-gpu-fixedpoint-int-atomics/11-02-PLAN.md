<objective>
Re-pin the ROCm resident-build parity gate to the CPU f64 anchor now that the resident
BUILD accumulates in u64 fixed-point (Plan 01), and add a determinism assert proving the
integer path is bit-equal across two runs. The new path is ~3600x more accurate than the
f32 path (5.9e-9 vs 2.2e-5 rel-to-anchor; exact in the cancelling regime), so the re-pinned
tolerance should TIGHTEN from the old f32-LDS gate toward exact where justified.

Purpose: SPEC item 2 -- parity GREEN, pinned to the CPU f64 anchor within ~1e-6 (ideally
tighter), CPU f64 bit-exact merge gate untouched, plus a 2-runs-bit-equal determinism assert
for the new integer path. def-f8u-01: NEVER pin two nondeterministic GPU f32 paths to each
other -- always pin to the anchor.

Output: re-pinned + determinism-asserting rocm tests that pass on hardware.
</objective>
