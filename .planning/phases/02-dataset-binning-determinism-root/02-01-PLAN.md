<objective>
Stand up the `lgbm-dataset` crate and deliver the first vertical binning slice: ingest a numeric
feature column, run `BinMapper::FindBin` (numeric branch) and `ValueToBin`, and prove the
`bin_upper_bound_` array (golden layer 1) and per-row bin-index vector (golden layer 2) are
bit-identical to committed C++ goldens. This is the determinism kernel — every downstream split
inherits these bins. Also establishes the Wave-0 golden-capture harness (xtask `bin-capture`
subcommand + focused C++ `bin_capture.cpp` + extended comparator + manifest) that all later Phase 2
plans plug into.

Implements: D-04 (one `lgbm-dataset` crate), D-03 (sequential per-feature seams), D-05 (minimal
internal ingestion surface — sampling entry only this plan), D-06 (four-source corpus capture
discipline, numeric subset), D-07 (three-layer golden granularity — layers 1+2 here).

Purpose: Lock the FP-boundary + tie-break determinism root before any storage, categorical, or EFB
logic is built, so a later divergence is unambiguously NOT in numeric binning (SC#5).
Output: `lgbm-dataset` crate (scaffold + `error.rs` + `bin_mapper.rs`), the `bin-capture` harness,
exact-equality comparator variants, extended manifest, and numeric golden fixtures + replay tests.
</objective>
