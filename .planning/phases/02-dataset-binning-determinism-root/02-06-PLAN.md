<objective>
Close the two blocking phase-02 verification gaps, which share one root cause: the
default-configuration in-memory ingest path forwards the RAW `min_data_in_leaf` as the
pre-filter threshold, whereas C++ forwards the SCALED
`filter_cnt = (min_data_in_leaf * total_sample_size) / num_dist_data`. With
`feature_pre_filter=true` (default) and sampling active (`sample_cnt < num_rows`), the
Rust threshold (e.g. 20) differs from C++ (`filter_cnt < 20`), so `is_trivial_` — and
every downstream feature store / EFB membership / split — diverges. The green suite
hides this because EVERY ingest parity test (and the C++ example golden) forces
`feature_pre_filter=false`, so the divergent default path ships with zero coverage.

Purpose: restore the bit-identical-on-default-configuration contract at the determinism
root (the phase goal) and prove it with a golden that fails-before / passes-after.
Output:
- A C++ golden through the scaled-`filter_cnt` `ConstructFromSampleData` path.
- A new Rust parity test replaying it (fails before the fix, passes after).
- The `filter_cnt` derivation fixed in a SINGLE source-of-truth helper used by both
  divergent sites (`ingest.rs::build_mapper` + `bin_mapper.rs::find_bin_from_column`).

Closes GAP-1 (CR-01/IN-02, SC#1, DAT-01) and GAP-2 (CR-02, SC#5 / ORA-03 bin stage, DAT-07).
</objective>
