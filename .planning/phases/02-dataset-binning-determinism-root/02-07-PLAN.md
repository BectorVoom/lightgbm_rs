The public ingest path (`from_mat`/`from_csr`/`from_csc` -> `finish_from_columns:122` ->
the non-bundled `Dataset::construct`, dataset.rs:84-94) builds a FeatureGroup for EVERY
feature, sets `used_feature_map_ = (0..num_features_)`, STORES bins for trivial features,
and IGNORES `cfg.enable_bundle`. C++ has a SINGLE `Dataset::Construct`
(dataset.cpp:325-441): it ALWAYS builds `used_features` from only `!is_trivial()` mappers
(337-343), groups over just those, sets `used_feature_map_[real] = -1` for every trivial
feature, and bundles because `enable_bundle` defaults to true (362-369). So a trivial
feature is DROPPED — no FeatureGroup, no bin offset, no stored bins. Any trivial feature
on the Rust path instead shifts `num_features_`, `feature2group_`, `feature2subfeature_`,
and every bin-offset / `num_total_bin_` — the exact determinism-root invariants this phase
exists to protect. The 02-06 golden was emitted to MATCH the divergent Rust path
(`StoredBinSingleGroup`, bin_capture.cpp:2140-2152 never consults `is_trivial_`), so the
parity test validates Rust-against-Rust on the trivial case and masks the divergence.

Purpose: restore the bit-identical-on-default-configuration contract at the determinism
root (the phase goal). The fix is REFERENCE-FAITHFUL: the in-repo `construct_bundled`
(dataset.rs:117-210) is ALREADY a correct port of the full single C++ `Dataset::Construct`
(it filters trivial features via `used_features` and dispatches on `enable_bundle`). The
non-bundled `construct` is a partial, store-everything variant the ingest path wrongly
uses. We unify onto the faithful path. CRITICAL: routing ingest through `construct_bundled`
makes it consume an `EfbSamples` and run `fast_feature_bundling`; that EfbSamples MUST be
built to the EXACT C++ `c_api.cpp:1352-1374` sampled-set convention, and the parity test
MUST assert the GROUPING output (feature2group_/feature2subfeature_), not just stored bins
— otherwise an incorrectly-built EfbSamples passes silently, which on a determinism-root
phase is a parity hole.

  is no longer reached from ingest — whichever the chosen dispatch (Task 1) selects.
- `finish_from_columns` dispatches on `cfg.enable_bundle`, routing the default path through
