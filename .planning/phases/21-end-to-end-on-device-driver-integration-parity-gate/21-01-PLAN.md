WR-01 `HistArena::swap` slot-aliasing fix is already landed (commit `c9a7fd1`, Phase 18)

(the live driver does NOT consume `HistArena` — it keeps per-leaf `DriverLeaf.hist:
Vec<f64>` — so this is a confirmation, not a rebuild). The `_with_cfg` refactor is the
minimal, additive way to make a constraint observably bind through the driver.
Output: an additive driver variant + a documented WR-01 confirmation. No trait-seam change,
no behavior change when `LGBM_CUDA_ON_DEVICE` is unset.
</objective>
