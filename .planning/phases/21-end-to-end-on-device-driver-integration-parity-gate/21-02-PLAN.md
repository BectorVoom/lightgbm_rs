<objective>
Broaden the STRUCTURE parity evidence for the on-device grow driver beyond the single
4-leaf case the Phase-20 gate proved, with THREE targeted D-02 risk cases — each cloning
the existing `learner_parity_on_device_structure_gate`, swapping only the corpus (and, for
case C, the driver entry point + cfg), and reusing the tie-aware cpu-f64 comparator verbatim:
  A. deep tree with >2 simultaneously-live leaves;
  B. no-split / single-leaf tree (`best_leaf == −1` break path);
  C. min_data_in_leaf / min_sum_hessian_in_leaf-constrained case (via `_with_cfg` from 21-01).

Purpose: ODL-18H hardening. Fast, high-signal, targeted cases (D-02 rejects a full sweep).
Every case pins to the cubecl-cpu f64 anchor (NEVER GPU-vs-GPU, def-f8u-01), STRUCTURE
bit-exact, leaf values ~1e-5, tie-aware `default_left`. NOTE (21-RESEARCH Pitfall 1):
the deep case broadens parity evidence ONLY — it does NOT exercise the WR-01 `HistArena::swap`
path (the live driver keeps per-leaf `Vec<f64>` histograms and never consumes HistArena).
Output: 3 new env-gated STRUCTURE gate tests, non-vacuous on the default cubecl-cpu lane.
</objective>
