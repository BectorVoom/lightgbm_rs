<objective>
Instrument the on-device grow driver so it reports its real device launches through the existing `phase_prof` COUNTS line (Landmine L-1). Today the launch counters bump only in the host-driven `learner.rs` per-leaf path; the on-device path returns early at `learner.rs:817` before any of them, and `grow_driver.rs` bumps none — so an on-device train emits `device_launches=0` and the line is suppressed by the `> 0` guard (Pitfall P-2). Without this counter, ODL-20 / SC-2 ("device_launches drops below 8,570/100-trees") is unmeasurable.

Purpose: Make the on-device launch-collapse OBSERVABLE for the Kaggle A/B harness (ODL-20), respecting the crate-cycle constraint (`phase_prof` is in lgbm-treelearner, ABOVE lgbm-compute).
Output: A compute-owned launch counter bumped at the driver's dispatch sites, folded into the `device_launches=` total + an `on_device=` sub-field, and a local unit test.
</objective>
