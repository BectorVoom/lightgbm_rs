<objective>
Reduce the per-leaf split-scan overhead of the learning-loop (if-else) split-finding
kernel — IFF measurement proves the scan is a material fraction of per-leaf compute.
The candidate lever is running the kernel's two independent passes (REVERSE then
FORWARD) on two lanes concurrently, combined by a final argmax, halving per-feature
scan latency without reordering either pass's f64 accumulation.

This is an **audit-before-wire** task. Project memory (`l3-on-gpu-fixhistogram-deferred`:
"host-device round-trip was NOT the bottleneck — profile before next perf assumption")
and the recent overhead campaign (q2z/sgu/tlk/mwr/ol8 → repeated hardware-confirmed
NULLs because production was already idiomatic) mean the default expectation is NULL.
Task 1 is a measurement that decides go/no-go. We do NOT manufacture a win.

Purpose: Either ship a parity-safe latency reduction backed by numbers, or produce a
documented evidence-backed NULL verdict + a reusable measurement harness.
Output: bench_split_scan.rs, 260620-8v4-FINDINGS.md, and (conditionally) an additive
2-lane variant in split.rs — all behind the bit-exact CPU f64 merge gate.
</objective>

# Key facts (verified, do not re-derive):
# - split_scan_body (split.rs:144) is the SINGLE source of split math, shared by
#   find_best_split_kernel (split.rs:395, CubeDim::new_1d(1), largely a TEST path),
#   find_best_splits_fused_kernel (split.rs:956), and mirrored by
#   find_best_split_kernel_f32 (split.rs:446) for the no-f64 hip path.
# - PRODUCTION per-leaf hot path = build_fix_scan_resident_f64_on (histogram.rs:2444),
#   CubeCount::Static(num_features,1,1), CubeDim::new_1d(1): ONE cube per feature,
#   ONE lane per cube. Features parallelized across cubes; each feature's scan is
#   single-lane sequential REVERSE-then-FORWARD.
# - Kernel is ALREADY branchless (select-encoded, cubecl-cpu MLIR constraint). The
#   `done` sticky flag emulates the C++ `break`. "Optimise" = structural/overhead
#   reduction, NOT branch removal.
# - phase_prof.rs: BUILD_NS / SCAN_NS AtomicU64 counters, gated by LGBM_PHASE_PROF=1,
#   phase_prof::dump(label) prints BUILD vs SCAN. BUILD+SCAN ≈ HISTSPLIT.
# - gfx1100: Plane + shared atomics YES, f64 NO. f64 path = cpu-only (cubecl-cpu);
#   hip path = f32 mirror. Any f64 cross-lane combine must NOT emit f64 device ops on hip.
# - cubecl 0.10 / cubecl-runtime 0.10 pinned. SharedMemory / sync_cube / Plane available.
