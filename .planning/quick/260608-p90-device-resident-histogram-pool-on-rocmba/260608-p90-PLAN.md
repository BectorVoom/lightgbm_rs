<objective>
Realize the L3 perf win deferred by 260608-oib: make the per-leaf histogram DEVICE-RESIDENT on RocmBackend from build through the split-scan, INCLUDING the subtraction trick, so the dominant per-leaf host read-back + re-upload is eliminated. Gated by a conservative eligibility check (pure numeric spine) so anything non-spine falls back to today's host path unchanged.

oib already shipped the on-device building blocks (`build_fix_compact_resident_f64_on -> (Handle, len)` bit-exact fix+compact; `fix_compact_kernel`; resident RAW build; on-device widen; `RocmBackend` holds RefCell device state). What is MISSING is the LIVE WIRING: a device-Handle slot mirror that follows the host `HistogramPool`'s slot bookkeeping, a Handle-in/Handle-out subtract, a Handle-consuming split-scan, and the learner control-flow that routes the pure-spine tree through them while keeping the CPU anchor and the non-spine paths byte-unchanged.

Purpose: cut GPU train wall-clock (nn7/oib baseline ~1.4 / 4.9 / 11.8s for small/medium/large) by keeping histograms on device across the whole per-leaf build->fix->compact->subtract->scan chain.
Output: a `resident_pool` device-handle mirror, resident subtract + scan kernels/launchers, the eligibility-gated learner wiring, a resident==host tree-equivalence rocm test, and a before/after GPU bench write-up.
</objective>
