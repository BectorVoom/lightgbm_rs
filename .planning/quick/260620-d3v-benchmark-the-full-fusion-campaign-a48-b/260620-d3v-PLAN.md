<objective>
Benchmark the full split-fusion campaign end-to-end on REAL workloads and prove it
changed only speed, not output. The campaign = three shipped changes:
- **a48** — smaller-child build+fix+scan fusion (unified BFS path).
- **b97** — larger-child subtract+scan fusion (no separate build).
- **c5v** — core-derived gate thresholds (`unified_bfs_threshold` ~100, `unified_subscan_threshold` ~130 at 16 cores).

Purpose: Quantify the cumulative train-time effect vs the exact pre-campaign baseline on
(a) a TYPICAL real dataset (where the gate keeps the campaign NEUTRAL by design) and
(b) a HIGH-DIMENSIONAL real dataset (where fusion fires and WINS), and validate that the
two paths emit a BIT-IDENTICAL model — the end-to-end correctness proof that the campaign
is a pure speed change.

Output: a threshold-agnostic bench harness, a high-dim dataset export script, an A/B run
with a bit-identical check, and a FINDINGS table with honest high-dim-win / typical-neutral
framing.

## A/B toggle mechanism (the core method — single binary, env only)
Every campaign change is gated by the two thresholds, and each fusion's BELOW-threshold
fallback is the byte-unchanged pre-campaign code (proven in a48/b97). Confirmed in code:
`lgbm_compute::unified_bfs_threshold()` / `unified_subscan_threshold()` read
`LGBM_UNIFIED_BFS_THRESHOLD` / `LGBM_UNIFIED_SUBSCAN_THRESHOLD` and **the env var takes
ULTIMATE precedence** over the core-derived default (`crates/lgbm-compute/src/lib.rs:430,473`);
`learner.rs:1537,1615` gate each fusion on `features.len() >= threshold()`. Therefore:

- **Campaign OFF (= exact pre-campaign baseline):**
  `LGBM_UNIFIED_BFS_THRESHOLD=18446744073709551615 LGBM_UNIFIED_SUBSCAN_THRESHOLD=18446744073709551615`
  (`usize::MAX` -> `features.len() >= MAX` is always false -> both fusions never fire ->
  original two-step build->scan + subtract->scan runs).
- **Campaign ON:** unset both vars -> core-derived defaults (~100 / ~130 at 16 cores).

This is cleaner and MORE accurate than checking out the pre-a48 commit: same binary, same
bench harness, zero harness skew — the only thing that changes between A and B is the two
env values. State this explicitly in FINDINGS.
