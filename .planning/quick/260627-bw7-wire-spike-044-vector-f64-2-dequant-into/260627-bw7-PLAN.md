Rewrite `fix_compact_kernel` (histogram.rs:2316-2412) so the natural stride-2 `[g,h]` cell
becomes one `Vector<_,2>` unit, per spike-044's recipe and the CONVENTIONS launch ABI. This is
the RECOMMENDED in-place rewrite — NO extra kernel launch (an extra launch is net-negative on
the launch-bound APU).

Signature changes:
- `h_raw: &Array<u64>` -> `h_raw: &Array<Vector<u64, N>>`
- `hist: &mut Array<f64>` -> `hist: &mut Array<Vector<f64, N>>`
- make the kernel generic `<N: Size>` (the cube macro REJECTS a literal `Vector<_,2>` — the
  "Punctuated::push_value" panic; CONVENTIONS spike-045 gotcha). N is FIXED to 2 by both
  callers (the [g,h] pair width = hip f64's max `io_optimized_vector_sizes` lane count); the
  bin->vector-index math below assumes N==2. Document that the caller hard-codes 2.

Index conversion: `base = slot_off[fi]` is a SCALAR cell offset and is always even (each
feature region is `2*num_bin` cells). In vector units the feature's pairs start at
`vbase = base / 2`; bin `w`'s `[g,h]` pair is at vector index `vbase + w`.

DEQUANT (vectorizes — the spike-044 cross-type-cast recipe): for each bin `w`,
`hist[vbase + w] = Vector::<f64,N>::cast_from(Vector::<i64,N>::cast_from(h_raw[vbase + w])) / Vector::<f64,N>::new(SCALE_F64)`.
The divide MUST broadcast via `Vector::<f64,N>::new(SCALE_F64)` (NOT `/ const` — the `Div<$lit>`
impl needs a literal token). SCALE_F64 = 2^30 = 1_073_741_824.0 (unchanged). 2^30 is exact in
f64, the per-lane cast is bit-identical to the scalar `i64::cast_from`/`f64::cast_from`, so the
dequant stays bit-exact by construction.

FIX (stays SCALAR — the dependent reduction is LOAD-BEARING, never reorder): read each bin's
pair `let p = hist[vbase + i];` then `p[0]` (g) and `p[1]` (h) via COMPTIME lane indices (a
comptime index is safe; the spike-045 segfault was a RUNTIME `vb[j]` index). Accumulate the
scalar `g`/`h` dependent fold in ASCENDING bin order with the branchless `select(take, .., 0.0)`
exactly as today (literal-init the loop-carried mutables; seed with `sum_gradient`/`sum_hessian`).
Write the most-freq pair: construct the result pair and store `hist[vbase + mfb]`. Prefer a
2-component vector construction; if cubecl exposes no 2-arg constructor, write the two lanes via
COMPTIME-indexed element writes into the array element (`hist[mi][0] = g; hist[mi][1] = h;`). If
neither comptime lane-write nor a 2-arg constructor compiles cleanly, STOP and apply the
documented FALLBACK in the action footnote rather than forcing it.

COMPACT (vectorizes — whole-pair copy): `hist[vbase + c] = hist[vbase + c + off]` (pair copy);
tail/degenerate zero via `hist[vbase + c] = Vector::<f64,N>::new(0.0)`. Same guard structure
(`off > 0`, `off >= nb`, `keep = nb - off`) and same ascending order as today.

Update BOTH launch sites to the spike-044 ABI (vector-unit lengths + vector_size positional arg
right after `CubeDim`):
- `fix_compact_f64_on` (histogram.rs:2527): h_raw is the quantized `raw_q` u64 buffer, hist is
  `h_hist` f64 — pass `2usize` after `CubeDim::new_1d(1)`, and
  `ArrayArg::from_raw_parts(handle, raw.len() / 2)` for BOTH (raw.len() is even).
- `build_fix_compact_resident_f64_on` (histogram.rs:2736): same — `2usize` after
  `CubeDim::new_1d(1)`, `from_raw_parts(h_raw, slot_len / 2)` and
  `from_raw_parts(h_f64.clone(), slot_len / 2)` (slot_len is even).
The underlying byte buffers are UNCHANGED; only the element type, the length-in-vector-units,
and the added vector_size arg change. Keep all V5 validation, the overflow guard, the
launch_unchecked SAFETY comments, and `#[cfg(feature = "rocm")]` intact. Do NOT touch the CPU
anchor (`subtract_histograms_cpu_native`, host `fix_histogram`/`build_fix_scan`) — rocm-track only.

FALLBACK (only if the in-place pair rewrite breaks the fix/compact scalar access cleanly): a
separate flat `Vector` dequant kernel launched before a dequant-stripped fix_compact. FLAG in
the SUMMARY that this adds a launch and is likely net-negative on the launch-bound APU; lean
toward declaring the wire net-negative and reverting rather than shipping a 2-launch fallback.
