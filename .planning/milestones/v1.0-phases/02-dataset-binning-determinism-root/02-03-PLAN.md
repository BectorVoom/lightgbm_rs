<objective>
Complete the `BinMapper` with the categorical `FindBin` branch (category→bin folding) and finish the
missing-value routing surface (`use_missing`/`zero_as_missing`/`MissingType`), then prove both against
committed C++ goldens — golden layer 1 (mapper internals) + layer 3 (categorical category→bin map) +
the per-row index vector. Categorical folding and missing routing have their own bit-exact tie-break
logic (descending-count stable sort, the `0.99f` float cut, the `min_data_in_bin` fold break, the NaN
dummy bin 0) separate from numeric binning.

D-07 (layer 1+3 categorical goldens), D-03 (sequential per-feature).

divergence is localized to categorical/missing, not numeric (SC#3, SC#5).

extension, and `categorical_folding`/`missing_edge_cases` golden tests.

| caller → `min_data_in_bin` / `max_bin` | untrusted ints driving the fold loop bound |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-07 | Tampering | categorical `value_to_bin` (`value as i32`, map lookup) | mitigate | `int_value < 0 => 0` and unknown-category `=> 0` guard every out-of-range/NaN input to the dummy bin; map lookup is by-key (no unbounded index); no `unsafe`. |
| T-02-08 | Denial of Service | categorical fold loop / distinct-category vectors | mitigate | Loop bounded by distinct category count and `max_bin`; `cut_cnt` derived from total sample count; the `min_data_in_bin && cur_cat_idx>1` break + `num_bin < max_bin` guard prevent unbounded bin growth on high-cardinality attacker input. |
| T-02-09 | Denial of Service | NaN/negative category accumulation | mitigate | Negatives folded into `na_cnt` deterministically; all-missing column produces a valid single-bin mapper, never a panic. |
| T-02-SC | Tampering | C++ categorical-capture harness compile | accept | Zero new packages (RESEARCH Package Legitimacy Audit). `LightGBM/`/`external_libs` read-only, untracked, never `git add`ed; capture at regen time only. No `[ASSUMED]`/`[SUS]` package → no blocking-human checkpoint. |
