<objective>
Build the full params-dict surface: a Python typed-value → string coercion layer
(D-08) feeding the existing `Config::from_params` (D-06, with its full alias table +
CHECK validation), plus a D-07 gate that raises a clear Python exception for
recognized-but-unimplemented params while still letting truly-unknown keys warn.

official params surface usable and safe — every param a user can set is either
honored, validated, or explicitly rejected (never silently ignored into divergence).
Output: `params.rs` coercion + D-07 gate, wired into `train`/`Dataset`, with a
params unit-test suite.

dependency is 08-02 (it rewrites the 08-02 train/Dataset `#[pyfn]` to route through
`build_config`). It sits in wave 5 purely to SERIALIZE shared-file edits — it touches
`crates/lgbm-python/src/lib.rs` and `python/lightgbm_rs/__init__.py`, which the
08-03 (wave 3) and 08-04 (wave 4) chain also edit. Same-wave concurrency would
conflict on those files, so 08-05 is sequenced after 08-04. This is an intentional
file-overlap serialization, not an under-specified dependency.
</objective>
